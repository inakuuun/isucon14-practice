# PR本文テンプレート

リポジトリ固有のPRテンプレートがない場合の標準形として使用する。変更規模と内容に合わせて調整し、空の見出しや自明な定型文は削る。小さな変更では節を統合してよい。

```markdown
## 概要

- <背景または解決する問題>
- <変更によって得られる結果>

## 変更内容

- <主要な変更と、その理由>
- <主要な変更と、その理由>

## 確認内容

- `<実行したコマンド>`: 成功
- <静的確認>: 問題なし
- <未実施の確認>: 未実施（<理由>）

## 影響範囲・対象外

- <互換性、運用、性能などへの影響>
- <今回変更していないこと>

## レビュー観点

- <重点的に確認してほしい判断、仮定、リスク>

## 関連issue

- Closes #<number>
```

コードや確認結果から裏付けられない成果、数値、テスト結果は書かない。関連issueがなければ、その見出しごと削除する。
